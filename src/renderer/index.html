      Privacidade

      Agente de IA · recursos

      Cada ação é uma chamada ao modelo. Se a tarefa pausar no limite, use Continuar no painel; receitas e planilhas em lote gastam menos ações.

      Receitas e módulos só rodam sobre dados já lidos; nenhum deles executa código dentro da página. O cache é opt-in porque só rende quando o provedor devolve tokens cacheados.
